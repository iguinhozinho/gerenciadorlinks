# Gerenciador de links

Este é um aplicativo mobile desenvolvido durante o minicurso de React Native da Rocketseat. Ele permite adicionar e gerenciar links importantes de maneira fácil e organizada.

## O que dá para fazer

- Criar um link com nome, endereço e categoria
- Filtrar os links por categoria
- Abrir um link salvo
- Excluir links

Os dados ficam salvos localmente no dispositivo.

## Como executar

Instale as dependências:

```bash
npm install
```

Depois, inicie o projeto:

```bash
npm start
```

Com o Expo aberto, escolha onde deseja executar o app:

- `a` para Android
- `i` para iOS
- `w` para web

## Tecnologias

- Expo
- React Native
- TypeScript
- Expo Router
- AsyncStorage
